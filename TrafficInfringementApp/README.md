# Traffic Infringement Application

This is an Android application designed for Traffic Police and Metro Police in South Africa.
It allows officers to:
*   Scan driver's licenses or ID cards to retrieve driver information and outstanding offenses.
*   Scan vehicle license disks to get relevant information about the car and its owner.
*   Issue traffic tickets directly through the application.

## Features (Prototype Stage)
*   Officer Login (Placeholder)
*   Dashboard for scanning options
*   Simulated scanning of driver and vehicle information
*   Display of driver and vehicle details
*   Form for issuing new traffic tickets (Placeholder submission)
*   Basic UI styling and navigation
